1. [attribute] Selector

Selects elements with the specified attribute.

[data-required] { border-left: 3px solid #e74c3c; }

This paragraph has the data-required attribute

2. [attribute="value"] Selector

Selects elements with the exact attribute value.

[type="submit"] { background-color: #2ecc71; }

3. [attribute~="value"] Selector

Selects attribute containing a specific word.

[class~="highlight"] { background-color: #f1c40f; }

This paragraph has the highlight class

This paragraph doesn't have highlight

4. [attribute|="value"] Selector

Selects exact match or begins with "value-".

[title|="top"] { border-bottom: 2px dotted #3498db; }

Header Content

Main Content (starts with top-)

Footer Content (not selected)
